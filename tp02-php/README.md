# TP2 - Tableaux et fonctions en PHP

Développement Web côté serveur - 2ème année Licence

## Lancer le projet
```bash
cd tp02-php
php -S localhost:8000
```
Puis ouvrir http://localhost:8000

## Contenu
- `index.php` : sommaire et Activité 1
- `fonctions.php` : toutes les fonctions réutilisables
- `donnees.php` : jeu de 10 étudiants
- `exercices/tableaux.php` : Activités 1 à 5
- `exercices/fonctions_demo.php` : Activités 9 à 11
- `exercices/etudiants.php` : Activités 6 à 8 et 12 à 18
- `gestion-etudiants.php` : mini-projet (Activité 19 + défi)
- `notes.php` : exercice maison 1
- `classe.php` : exercices maison 2 et 3
- `questions.txt` : questions de réflexion
